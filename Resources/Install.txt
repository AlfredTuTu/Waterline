Waterline 0.1.0 — installation / 安装说明

1. Quit an existing Waterline instance, then drag Waterline.app to Applications.
2. Eject the disk image and open Waterline from Applications.
3. If macOS blocks the first launch, open System Settings > Privacy & Security,
   find the Waterline message, choose Open Anyway and confirm the system prompt.

The island shows one account. Click for all accounts, drag cards to reorder, and
use the pin menu to select the daily account. The Waterline menu contains ordering,
collapse and quit. Language selection is in the menu-bar menu. There is no launch-at-login feature.

Saved logins are detected automatically; macOS may ask you to authorize Keychain
access. Claude usage can come from matching desktop history or a new supported
Claude Code session. Existing custom status lines are not replaced. Antigravity requires
its native CLI to be running and signed in. No API balance accounts are offered.
Updates for this release are manual: quit the app and replace it with a newer copy.

Uninstall: remove Waterline.app. Account records in
~/Library/Application Support/Waterline remain. If Waterline installed its Claude
statusLine command, remove only that matching statusLine entry from
~/.claude/settings.json; a settings-waterline-backup-*.json file holds the original.
Do not restore an old full settings backup over subsequent unrelated changes.

1. 先退出已运行的Waterline，将Waterline.app拖到Applications（应用程序）。
2. 推出磁盘镜像，从应用程序打开Waterline。
3. 若首次打开被macOS拦截，打开“系统设置→隐私与安全性”，找到Waterline提示，
   点击“仍要打开”并按系统提示确认。

灵动岛显示一个账号，点击查看全部账号，拖动卡片排序，图钉菜单选择日常账号。
底部Waterline菜单提供排序、收起和退出；菜单栏菜单提供语言选择，不提供开机启动功能。
首次运行自动检测本机登录，钥匙串可能要求确认授权。Claude额度可读取同一账号的
桌面版历史记录，或由新建的受支持Claude Code会话提供；不会替换已有的自定义状态栏。Antigravity需要已登录并运行的CLI。
本版本不提供API余额账号。更新方式为手动退出并替换应用。

卸载时删除应用。本机账号记录会保留。如果Waterline安装了Claude
statusLine接收命令，请仅删除~/.claude/settings.json中对应Waterline的statusLine项；
同目录的settings-waterline-backup-*.json保留原设置，不要用旧完整备份覆盖后续其他修改。
